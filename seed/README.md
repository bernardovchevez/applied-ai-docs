# Harbor Line seed library

Synthetic **Harbor Line** media-ops documents (54 `.md` / `.txt` files) plus `sharepoint-meta.json`.

This is the **bootstrap pack** for localhost: import into the catalog via the docs UI (**Import seed library**) or `POST /admin/seed-from-synthetic`, then **Publish** to the platform lake.

Do not edit these files for day-to-day demos unless you are extending the seed pack itself. Use the catalog UI for live document changes.
